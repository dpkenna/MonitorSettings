# Set-MonitorSettings.ps1

A PowerShell script that sets the primary monitor, resolution, orientation and scaling of one monitor on Windows. Changing the primary monitor keeps your custom monitor arrangement.

## Setup

### Let the script run

Downloaded scripts are blocked unless they're signed. After checking the file, unblock it:

```powershell
Unblock-File .\Set-MonitorSettings.ps1
```

If it still won't run, check `Get-ExecutionPolicy -List`. If CurrentUser or LocalMachine shows `AllSigned` or `Restricted`, run:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Don't use `Unrestricted` or `Bypass` for your whole account, because they remove the protection for every script.

### Find your monitors

```powershell
.\Set-MonitorSettings.ps1 -List
```

Example output:

```
Name      Device        Primary     X  Y Width Height RefreshHz Orientation Scaling
----      ------        -------     -  - ----- ------ --------- ----------- -------
DELL P24  \\.\DISPLAY2    False -1920  0  1920   1080        60 landscape       100
LG 27UK   \\.\DISPLAY1     True     0  0  3840   2160        60 landscape       150
DELL P24  \\.\DISPLAY3    False  3840  0  1920   1080        60 landscape       100
```

What the columns mean:

- **Name** is the name the monitor reports to Windows. It's often a brand or model, not a name you chose.
- **Device** is Windows' name for the display output.
- **X, Y** give the position of the monitor's top-left corner in pixels, measured from the primary monitor's top-left corner at (0, 0). A negative X means the monitor is to the left of the primary, and a positive X means it's to the right. A negative Y means it's above the primary, and a positive Y means it's below.
- **Primary** is `True` for the monitor at (0, 0).

To choose a monitor with `-Monitor`:

- If its name is unique, use the name or any part of it (`'LG'`).
- If two monitors share a name, use the device (`'\\.\DISPLAY3'`). Use the Device value, not X: X changes whenever the primary monitor changes, and Device doesn't.

## Parameters

| Parameter | Values | Notes |
|---|---|---|
| `-List` | switch | Shows the connected monitors and stops. |
| `-Monitor` | name, part of a name, `\\.\DISPLAYn`, or `n` | Required unless you use `-List`. An exact device or name match is tried first, then a partial name match. It must match exactly one monitor. |
| `-Resolution` | e.g. `1920x1080` | Must be a mode the monitor supports. |
| `-Orientation` | `landscape`, `portrait`, `landscape-flipped`, `portrait-flipped` | If you change between landscape and portrait without `-Resolution`, the width and height are swapped for you. |
| `-Scaling` | `100`, `125`, `150`, `175`, `200`, `225`, `250`, `300`, `350`, `400`, `450`, `500` | Same setting as Settings > Display > Scale. Each monitor allows only up to a certain maximum. |
| `-SetPrimary` | switch | Makes this monitor the primary one. |

Anything you leave out stays as it is. If nothing would actually change, the script doesn't touch the display, so the screen doesn't flicker.

## Examples

```powershell
# Make the LG the primary monitor
.\Set-MonitorSettings.ps1 -Monitor 'LG' -SetPrimary

# Set the right-hand Dell to 125% scaling, choosing it by device
.\Set-MonitorSettings.ps1 -Monitor '\\.\DISPLAY3' -Scaling 125

# Rotate a monitor to portrait
.\Set-MonitorSettings.ps1 -Monitor '\\.\DISPLAY2' -Orientation portrait

# Make a monitor primary at a set resolution and scaling, all in one call
.\Set-MonitorSettings.ps1 -Monitor '\\.\DISPLAY3' -Resolution 1920x1080 -Scaling 100 -SetPrimary
```

### Switching between setups

To switch between setups (for example, gaming on one screen and working on another), put the calls for each setup in its own small script, and run that script:

```powershell
# Example: make the right-hand Dell primary at 100% scaling
& "$PSScriptRoot\Set-MonitorSettings.ps1" -Monitor '\\.\DISPLAY3' -Scaling 100 -SetPrimary
```

To run it from a desktop shortcut, use this target:

```
powershell.exe -ExecutionPolicy Bypass -File "<path to your script>.ps1"
```

`-ExecutionPolicy Bypass` here applies only to that one launch. Add `-WindowStyle Hidden` before `-File` if you don't want a console window to flash. Leave it out while testing, so you can see any error messages.

## How it works

- **Changing the primary monitor.** Windows treats the monitor at position (0, 0) as the primary. The script moves every monitor by the same amount, so the chosen one lands at (0, 0) and the monitors stay in the same positions relative to each other. The new layout is applied in one change with `SetDisplayConfig`, the same Windows API that Settings > Display uses.
- **Keeping the arrangement.** Every display change includes each monitor's position. If the position is left out, Windows puts the monitor back in its default place.
- **Scaling.** Scaling uses the per-monitor setting that Settings > Display > Scale uses. Microsoft doesn't document this setting, but common tools such as SetDPI use it.

## Troubleshooting

| Problem | Fix |
|---|---|
| "is not digitally signed" | See [Let the script run](#let-the-script-run). |
| "More than one monitor matches" | Two monitors share a name. Use the device (`\\.\DISPLAYn`) instead. |
| "No monitor matches" | Run `-List` and copy the name or device exactly. |
| The wrong screen changes | Windows can renumber `\\.\DISPLAYn` after you unplug a monitor or update the graphics driver. Run `-List` again and update your calls. |
| "that mode isn't supported by this monitor" | The resolution in `-Resolution` isn't one the monitor offers. Check Settings > Display for the resolutions it supports. |
| "supports scaling from 100% to N%" | Pick a scaling value no higher than N. |
| Scaling stops working after a Windows update | Windows may have changed the undocumented scaling setting. Changing the primary monitor and the resolution should still work. |
| A monitor shows `(no name)` | Use its device instead. |
